BUILD THE APK (free, no Android Studio, ~5 min)
1. Make a free GitHub account, create a NEW repository (private is fine).
2. Upload everything from this folder (drag & drop on github.com, or use git). Keep the .github folder.
3. Open the repo > Actions tab > "Build APK" > Run workflow.
4. When it turns green, open the run > Artifacts > GymRoutine-APK > download, unzip -> app-debug.apk.
5. Copy to your phone, open it, allow "install unknown apps". On first run allow Notifications.
